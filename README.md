## Stub Links for our Mechanical CAD Assemblies

Our CAD is visible in Onshape. Please feel free to use it for your own designs - I have added an open sourced license file to this project repository.

The 2025 CAD included a regular 3D printed shell which is attached to the top of the cap holders on our robot, which we are working on replicating a version of the A-Team's color tab idea for future competitions.

The current CAD has new wheels, a mount for the IMU below the midplate, and the new shell design described earlier. The new shell unfortunately will not be at RoboCup 2026.
